# Easy Peasy Recipes

A mobile-first recipe recommendation app that helps Shankar decide what to cook using what he already has at home.

## What is implemented

- Home recommendation feed with expandable controls
- Realistic seeded Shankar test profile
- Kitchen management for fridge, shelf, and utensils
- Friend following with Anjali, Varun, and Chandan
- Saved recipes
- Recipe detail view with Text, Audio, and Video modes
- Short and Long recipe variants
- Cooking mode with step navigation, timers, and simulated audio playback
- Match scoring based on ingredients, utensils, time, cuisine, and friend recommendations

## Run locally

This is a dependency-free static app.

```bash
python3 -m http.server 4173
```

Then open:

```text
http://localhost:4173
```

## Test profile

The seeded test profile is Shankar's kitchen:

- Fridge: cucumber, carrot, tomato, onion, curd, lemon, green chili, coriander, ginger, capsicum
- Shelf: cumin seeds, mustard seeds, soy sauce, hot sauce, rice, salt, pepper, turmeric, red chili powder, besan, oats, peanuts
- Utensils: microwave, grater, chopping board, rice pot, pan, kadai, frying pan, sauce pan, pressure cooker, tawa, bowl, knife

Use the Profile tab to reset the demo data at any time.
